# Проверка перед публикацией, 15.10.2026

- Сборка TypeScript/Vite прошла.
- 10 автоматических тестов расчётов и действий бюджета прошли.
- Реальные Supabase Auth и PostgREST проверены на двух временных аккаунтах: вход, сохранение копеек, новый клиент с тем же аккаунтом, блокировка чужого чтения/записи, конфликт revision, шесть повреждённых импортов с полным откатом, закрытые резервные копии, запрет анонимного доступа.
- В браузере проверены вход, формы регистрации/восстановления, создание операции, перезагрузка, JSON-экспорт и выход. JavaScript-ошибок нет.
- Экран входа, аналитика и форма операции проверены на ширинах 390, 768, 1024, 1366, 1920, 2560. Горизонтального переполнения нет. Скриншоты в qa/screenshots.
- npm audit: 0 уязвимостей после обновления Vite до 8.3.4.
- Supabase security advisor: по таблицам/RLS замечаний нет. Есть предупреждение проекта о выключенной проверке паролей по базе утечек (leaked password protection); настройка не менялась. Перед клиентским запуском стоит включить её, если она доступна на выбранном тарифе.
- Доставка подтверждений и восстановления на реальную почту не проверена. Нужны корректные URL Configuration и SMTP. Подтверждение почты не отключалось.

Это учебное приложение с одним личным бюджетом на аккаунт. Совместного доступа нескольких аккаунтов к одной семье, живого ИИ и автоматического переноса истории диалогов нет.

Опубликованная версия также прошла браузерные проверки реального входа, сохранения, перезагрузки, JSON-экспорта, выхода и шести размеров экрана. Проверенная копия прежней базы (11 категорий, 3 операции) подготовлена отдельно от репозитория; для импорта владелец должен войти в свой новый аккаунт.
